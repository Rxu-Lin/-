# KOL Management Portal

Static single-page portal for managing KOL resource files and authorization records.

## Deploy

This site can be published directly with GitHub Pages from the repository root:

1. Push `index.html` and `.nojekyll` to the default branch.
2. In GitHub, open **Settings > Pages**.
3. Set **Source** to **Deploy from a branch**.
4. Select the default branch and `/ (root)`.
